# けいさんチャレンジ

子ども向けの足し算・引き算練習アプリです。

## v1.1（正式版）の実装内容

- 繰上り・繰り下がりのない1桁の足し算・引き算
- 電卓式の数字入力。数字を押すと即時に正誤判定
- 正解後は短いフィードバックを表示して自動で次の問題へ進む
- 誤答時は「ざんねん！」のポップアップに問題・入力した答え・正解を表示。「わかった」を押すまで待ち、押したら次の問題へ進む
- 譜読みアプリに合わせた数字ボタンの配色・押下フィードバック
- 「全パターン練習」と「ランダム練習」の選択
- 全パターン：0を含む順序別55問をシャッフルして一度ずつ出題。間違えた問題は最後に復習し、全問正解で終了
- 正解数・復習の残り問題数を表示。いつでも途中終了できる
- ランダム：好きなだけ練習し、誤答はポップアップで確認して次の問題へ進む

学習実績は子ども別にこの端末のブラウザへ保存します（v0.5以降の練習が対象）。端末間の同期はありません。途中の問題進捗は保存せず、途中終了後は最初から練習します。

- 一桁回答では「けす」「⌫」を非表示にし、0を中央に配置
- 初期選択は全パターン練習
- 保護者向けレポート：日ごと／1週間（月曜〜日曜）／1か月（今日を含む30日）
- 回答数・正答率・練習時間の目安・練習日数・やり直して正解した回数・全パターン完了回数
- 週間グラフを横スワイプ／スクロールして過去の週へ移動。前の週・次の週・今週ボタンも対応
- 週間グラフの日の棒をタップすると日別レポートを表示。閉じると同じ週へ戻る
- 日別の回答数と正答率、計算種類別の集計、間違えた問題、褒めポイント
- 子ども別プロフィールを選択。追加・名前変更は保護者画面に集約
- 練習時間はポップアップ・保護者画面・非表示中を除外し、1問最大2分で集計

- 日ごと画面と日別レポートは左右スワイプ／前日・翌日・今日ボタンで日付を切替
- 週間・月間グラフから日別レポートを開ける。閉じると元のグラフへ戻る
- 左スワイプで翌日、右スワイプで前日。縦スクロールや短いドラッグでは日付を変更しない

## タイムアタックとごほうび

- 全パターン練習で「タイムアタックでちょうせん」を選択（初期ON）。通常練習としてOFFにもできます。
- 55問と誤答の復習をすべて正解したときだけ、自己ベストの対象になります。
- 子ども別・足し算／引き算別に自己ベストを保存。初記録または厳密に速い記録でお祝い画面を表示します。
- 正解演出・誤答確認・保護者画面・お祝いプレビュー・非表示中は時計を停止。復習問題の回答時間も含めます。
- タイムアタックは1問2分の上限を設けません（保護者レポートの時間の目安とは異なります）。
- 通常のアドレスは正式版です。デバッグ用の表示とお祝い確認ボタンは出ません。
- 末尾に `?debug=1` を付けた場合だけデバッグ版となり、お祝い演出を何度でも確認できます。プレビューでは実績と自己ベストを変更しません。
- 正式版：https://garoad9901.github.io/calculation-trainer/
- デバッグ版：https://garoad9901.github.io/calculation-trainer/?debug=1
- 保護者画面の「正式版の共有QRコード」から正式版URLを共有できます。

## 10をつくる繰り上がり練習（v1.1）

正式版の開始画面で「10をつくる たしざん」を選択します。

- 後ろの数を分け、「10をつくる → 残りを求める → 答え」の3段階で回答します。
- 途中の正解は自動で次の手順へ進み、最後の答えが正解したときだけポップアップを表示。その中のボタンで次の問題へ進みます。
- 分けた片方が0になる問題を除外し、標準は36通り（和が11〜18）です。
- 「保護者向け」→「繰り上がり練習の設定」で、最初の数（足される数）の下限を2〜9から選択。子ども別に保存し、次の練習から反映します。
- 全パターン／ランダムに対応。誤答は同じ手順をやり直し、全パターンでは最後にも復習します。
- 学習記録は子ども別に保存し、保護者レポートに「10をつくる たしざん」として表示。途中の正解手順は回答数に加算せず、誤答と最後の正解を記録します。
- タイムアタックは3手順の回答時間を計測。ポップアップや正解後の待ち時間は除外し、子ども・出題範囲別に自己ベストを保存。既存の足し算・引き算の自己ベストはそのままです。

## 独立した機能テスト：繰上りの練習 v0.6

- テストURL：https://garoad9901.github.io/calculation-trainer/carry-test.html
- 写真のように後ろの数を分け、「10をつくる → 残りを求める → 答え」の3段階で回答します。
- 例：8＋7 → 7を2と5に分ける → 10＋5＝15。「写真の8＋7をためす」から直接確認できます。
- 全36通り（1〜9の和が11〜18、分けた片方が0になる問題は除外）またはランダム。誤答は確認後に同じ段階へ戻り、全問練習では最後にも再出題します。
- 保護者の設定で最初の数（足される数）の下限を2〜9から選択。全問・ランダムの両方に適用し、問題数も更新します。設定のみこのブラウザに保存します。
- 途中の正解は自動で次の段階へ進み、最後の答えが正解するとポップアップから次の問題へ進めます。
- テストの結果は保存せず、正式版の履歴・タイム・自己ベストには反映しません。
- 状態管理は carry-engine.js に分離。検証は `node tests/carry-engine.test.cjs`。
